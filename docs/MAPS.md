# Карты — профиль ExpandedWorld

Дата: 2026-11-05. Игра: 42.21.0. Текущий PersonalKnox: 0.4.40.

## Состояние

На все выбранные карты и обязательные тайлпаки оформлены подписки; Steam
подтвердил установку без ожидающих загрузок. Подготовлен расширенный профиль
на основе **актуальных 51 модов**, а не старого списка из 35.

В `mods/default.txt` пока остаются прежние 4 карты (130 клеток): во время
подключения игра оказалась запущена, поэтому список не переписывался.
Существующие миры и их `mods.txt` не изменялись.

Зависимости: `tikitown_tiles` (3046728955) для Tikitown и
`UnofficialMappersCommunityTilePack` (3628736763) для Cathaya Valley.
Не включать отдельные TikitownPower/TikitownScrapWorks и Cathaya highway:
это дополнительные функции/варианты, не часть проверенного профиля.

На текущих файлах не найдены пересечения клеток между выбранными картами,
различающиеся Lua-файлы по одинаковым путям или различающиеся тайлпаки с одинаковыми
ID. Все объявленные зависимости выбранных карт присутствуют в профиле.
Проверка включает актуальные моды Viewpoint, Knox и пользовательские добавления.

Файлы: `profiles/ExpandedWorld-mods.txt`, `profiles/ExpandedWorld-audit.json`.
Первый файл — полный снимок подготовленного списка, а не автоматически
подключённый игровой пресет. Для применения без потери более новых настроек:

```sh
python3 tools/apply_expanded_maps.py --apply
```

Скрипт заново собирает профиль поверх текущего списка, выполняет аудит,
проверяет подписки/готовность файлов Steam, отказывается применять при запущенной
игре, делает резервную копию и атомарно обновляет только `mods/default.txt`.
Новый набор предназначен для **нового мира**. Прямое копирование старого снимка
поверх изменённого списка не требуется.

## Что исключено из этого набора

На 3829712469, 3477336014, 3659676359, 3486814612, 3747595202, 3728357493,
3602388131 и 3747335481 подписки отсутствуют — проверено через Steamworks.
Часть файлов, скачанных для анализа, ещё находится в Workshop; они не включены.

| Карта | Причина решения |
|---|---|
| Real USA | Отдельный ранний мир, не расширение Knox Country; отменён по просьбе пользователя |
| LittleTownship B42 | Те же четыре клетки, что у действующего Maplewood |
| AnruisiTown | Пересечение с Camden: 50,44; 50,45; 50,46 |
| Greenleaf | Пересечение с Constown: 24,42; оставлен более крупный Constown |
| Greenport | Путь MapUIReplacement.lua совпадает с Tikitown, содержимое разное; оставлен Tikitown |
| Haven Fall | Путь ALICEPacks_HotbarAttachDefinition.lua совпадает с действующим Iris Eyot, содержимое разное |
| Fort Waterfront B42 | Три тайлпака с ID 830/7001/6985 отличаются от выбранного Community Tile Pack |
| Falcon Ridge | Разные файлы двух собственных разделов карты занимают 41,52 и 42,52; отложен до проверки дорог |

Некоторые такие пересечения могут быть задуманы автором или решаться адаптером.
Это причины исключения из текущего набора, не доказательство, что каждый из этих
модов всегда сломан. После исправления/проверки можно пересмотреть решение.

Предыдущая рекомендация 675 клеток с Greenleaf заменена этим профилем:
выбраны Constown вместо Greenleaf, Tikitown без Greenport и Cathaya без
Fort Waterfront. Так можно расширить набор без найденных указанных коллизий.

## Что ещё не подтверждено

Статический аудит не доказывает загрузку мира, правильность комнат/зданий,
работу NPC, моделей Viewpoint, дорог, анимаций и FPS. RaccoonCity содержит
тематические вещи, машины и дополнительные обработчики; её нужно проверить
не только как набор зданий. Изменения авторов после обновления требуют нового аудита.

Следующий этап: применить профиль после закрытия игры, создать отдельный новый
тестовый мир, проверить комнаты и маршруты NPC и сравнить производительность
по `docs/PERFORMANCE.md`. Отсутствие вылетов и влияния на FPS пока не подтверждено.
