## 0.4.5 — видимые реплики над NPC

Запуск 0.4.4 (15:06–15:25) подтвердил загрузку Java-ядра 0.4.4, Lua-адаптера и
`PersonalKnoxAPI`. В `players.db` основного мира есть записи журнала `dialogue`
(id 10, 24, 5, 20, 22): автоматические реакции срабатывали. Визуально фраз не
было, потому что `IsoGameCharacter:Say` для NPC уходит в `ChatManager.showInfoMessage`,
а не рисует пузырь над персонажем. В 0.4.5 `say` вызывает `addLineChatElement`
(`ChatElement` над персонажем) с откатом на `Say`; Java-ядро не менялось, JAR
остаётся 0.4.4. Нужен новый запуск для проверки пузыря.

Диагностика в этом запуске была включена уже после входа в мир
(`Lua/ModOptions.ini`, 15:13), поэтому строка `[capabilities]` не печаталась —
это не ошибка мода. Для следующей проверки включать диагностику до загрузки мира.

- Снабжение PersonalKnox теперь считает только чистые пригодные повязки; резерв — минимум две. Самостоятельное изготовление тряпок пока не реализовано.
