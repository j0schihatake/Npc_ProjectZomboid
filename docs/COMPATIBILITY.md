# Проверка текущей сборки

Дата: 2026-11-05. Игра: 42.21.0, Viewpoint: 0.1.6.1. Проверка манифеста и прошлого журнала не доказывает совместимость всех функций в игре.

## Подтверждённая проблема и исправление

- `ViewpointExtendedSupport` отключён в общем списке и последнем сохранении: в журнале есть Byte Buddy `Cannot assign class java.lang.Object to class viewpoint.interact.LootTargets$Target` непосредственно при его патче `LootTargets.aimed`.
- `ProjectViewpointQOLLegacy0.1.6` оставлен. Его отдельное предупреждение `ThirdPerson.active` по просьбе пользователя отложено.
- Исправлены наши подписи процентов в переводе Ammo Weight: больше нет сырого `%`, который вызывал предупреждение форматирования.
- Наши русские подписи контекстного меню вынесены из Lua в JSON через `getText`; 2026-11-05 пользователь подтвердил в игре: «текст стал норм».

## Изменения интерфейса

- Установлен `DGVViewpointEyes`. Полосы здоровья зомби, цифры урона, контур и комбо отключены в его пользовательском конфиге.
- Дополнительные карта/компас/пинги/ежедневные сводки Eyes отключены, чтобы не добавлять ненужную работу. Стандартная миникарта сохранена.
- Это новый мод для текущей сборки: необходима проверка в игре; другой полноценный HUD параллельно не подключён.

## Автоматизация персонажа и NPC

### Project A-Life — отдельная непроверенная NPC-система

Проверено описание автора Workshop 3803984183 через Steam API, 2026-11-05:
версия 1.4.6 заявляет поддержку B42.21, SP/COOP/MP. Автор рекомендует один
NPC-мод на сохранение; это общая рекомендация, не доказанный результат теста
конкретной пары A-Life + Knox. Совместимость нашей сборки не подтверждена.

Персональный API привязан к KnoxEventExpandedNpc, MetaNpcCharacter и IsoNpcPlayer.
A-Life помечает свои тела IsoZombie через `ProjectALifeOwned`. В текущих
Reactions/Supplies эта метка не учитывается: такие персонажи могут считаться
зомби/опасностью вместо людей. Простой фильтр метки не решает отношения фракций,
враждебность, выбор цели Knox, урон, команды, учёт отряда и производительность.
Не объявлять совместимость после единственного исправления фильтра.

Паритет по возможностям A-Life запланирован отдельной программой — раздел 4А в
`ROADMAP.md`: свои фракции, постоянная симуляция, тактика отрядов, аутпосты и
радио на публичных API Knox, собственным Java-кодом. A-Life не подключается как
зависимость, его код и контент не копируются. Первый обязательный шаг — пропуск
тел с `ProjectALifeOwned` во всех наших циклах зомби (реакции, снабжение,
баррикады, диагностика); сейчас он не реализован.

По текущему FAQ автора в основном A-Life 1.4.6 ещё нет найма спутников; это
планируемая функция. Возможности сторонних расширений здесь не проверялись.
Тестировать A-Life отдельным набором и отдельным миром; отключение Knox потребует
также отключить текущий PersonalKnox. В основной набор A-Life не добавлялся.

Источник: https://steamcommunity.com/sharedfiles/filedetails/?id=3803984183

- Auto Eat, Auto Drink и Auto Medic не считаются проверенной автоматизацией Knox NPC только потому, что работают на игроке.
- Auto-Eat 0.2.7 проверен по исходникам: подписан на `OnPlayerUpdate`, берёт настройки персонажа и вызывает `player:Eat(food, fraction, false)` напрямую; обычная `ISEatFoodAction` и её анимация не используются.
