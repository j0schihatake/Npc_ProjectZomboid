# A-Life модуль PersonalKnox

Отдельный Java-пакет `personal.knox.alife` со своим функционалом. A-Life не
подключается как зависимость, его код и контент не используются; сходство только
функциональное. Модуль не заменяет Knox и не создаёт игровые объекты — это
модель и решения, которые игровой адаптер будет применять через API Knox.

## Статус

- Реализованы `Faction`, `Squad`, `Relations`, `AlifeWorld`, `AlifeEvent`.
- Есть детерминированный тик с бюджетом, деление на ближние/дальние отряды,
  расход припасов, память обид и возврат с подкреплением.
- Игровой адаптер не подключён: модуль не вызывается из Lua и не меняет 0.4.4.
- Тесты входят в общий прогон `BrainTest`; сборка `python3 tools/build.py`.

## Границы

- В модуле нет игровых классов, создания NPC, изменения мира и инвентаря.
- Данные фракций свои; 148 фракций и 9 аутпостов A-Life не копируются.
- Один владелец поведения: ближние отряды полностью остаются на Knox, модуль
  отдаёт событие `NEAR_SQUAD` и не командует ими напрямую.
- A-Life и наш модуль одновременно не запускаются; фильтр `ProjectALifeOwned`
  остаётся защитой на случай отдельной установки A-Life пользователем.

## Модель

| Класс | Назначение |
|---|---|
| `Faction` | id, имя, отношение, базовая репутация −100..100 |
| `Squad` | фракция, состав, здоровье, припасы, задача, позиция и цель |
| `Relations` | репутация, события, затухание, память обид и мести |
| `AlifeWorld` | отряды, детерминированный тик, бюджет, ближняя/дальняя зона |
| `AlifeEvent` | `NEAR_SQUAD`, `FAR_MOVE`, `FAR_RETURN`, `FAR_ENCOUNTER` |

Правила `Relations`: атака −25, ограбление −15, помощь +20, торговля +8;
затухание 1 пункт в игровой день до нейтрального; месть возможна через 2–7 дней
после атаки при репутации не выше −10; помощь отменяет месть.

Тик `AlifeWorld`:
- не больше `budget` операций за вызов; непрошедшие отряды не меняются;
- в радиусе 80 клеток — только событие `NEAR_SQUAD`, без симуляции;
- дальше — шаг 8 клеток к цели, расход припасов, при нуле припасов `FAR_RETURN`,
  у патруля редкая встреча;
- одинаковый seed и входные данные дают одинаковые события.
