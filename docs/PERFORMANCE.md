# Проверка производительности

Требование пользователя: доработки не должны заметно ухудшать производительность.
Автотесты ограничений не заменяют замеры в игре. Замеры FPS/времени кадра
для 0.4.4 пока не выполнены; отсутствие ухудшения не подтверждено.

## Ограничения по коду

- Реакции: одно событие EveryOneMinute; максимум 169 клеток, 256 движущихся
  объектов, 24 сохранённых цели, 8 найденных NPC и 4 обработанных NPC за опрос.
- Видимость: не больше 4 × 24 проверок; нет полного списка зомби мира.
- Направления 0.4.4: ближайшая цель выбирается в прежнем цикле видимости.
  Новый обход или обработчик кадров не добавляется; расчёт сектора на Java
  выполняется только для уже разрешённой к произнесению фразы react_zombies.
- При отключённых реакциях нет опроса мира. Состояния Java ограничены 128 NPC.
  SQLite используется при сборке; в игре реплики читаются из ресурса JAR.
- Диагностика доступных Lua-классов: одна строка на загрузку мира без обхода.
- Ограничения снабжения и баррикадирования проверяются отдельными Lua-тестами;
  их реальная стоимость и одновременная работа ещё требуют замеров.

## Сравнение в игре

1. Дождаться завершения установки Steam; не совмещать замер с загрузкой/установкой
   модов. Не менять настройки камеры, графики, лимит FPS, время и погоду между
   сравнениями. Зафиксировать версии и список всех модов.
2. На независимых копиях одного исходного мира сравнить 0.4.3 и 0.4.4. Первое
   прохождение участка использовать для прогрева загрузки и Java; его не считать.
3. Проверить три одинаковые сцены: спокойная база; несколько следующих NPC;
   бой отряда с толпой. Отдельно проверить движение через плотный город с Viewpoint.
4. Сделать не менее трёх повторов каждой сцены, чередуя версии. Сравнить медиану
   FPS, 95-й процентиль времени кадра и заметные паузы; зафиксировать число NPC
   и зомби. В бою полная повторяемость невозможна, поэтому один прогон недостаточен.
5. Если разница превышает естественный разброс повторов, найти причину до выпуска.
   При ограничителе FPS одинаковый счётчик не доказывает одинаковый запас CPU/GPU.

Запись результата: версия/commit, мир, моды, настройки, сцена, три измерения,
медиана FPS, p95 времени кадра, паузы и ошибки журнала. Пока нет таких данных,
указывать только подтверждённые лимиты, не обещать нулевое влияние на FPS.
