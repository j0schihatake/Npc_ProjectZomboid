# Personal Knox

Личное Java-дополнение к Knox Event Expanded для Project Zomboid 42.21.0.
Ничего не загружается в Workshop или удалённый репозиторий.

## Что есть сейчас

- Версия 0.2: автоматические реакции на замеченных зомби, толпу, ранения, дождь, темноту и тела поблизости.
- Русские разговоры с членами отряда: мораль, отношения и смелость влияют на выбор фразы.
- Быстрые приоритеты земледелия, рубки и сортировки. Саму работу выполняет Knox; нужны убежище, зоны и инструменты.
- Простой сбор необходимого в текущем доме: NPC объявляет план, ждёт подтверждения или выполняет после уведомления.
- Проверка стрельбы с высоты через отчёт `[PersonalKnox][elevation]` в `~/Zomboid/console.txt`. Стрельба пока не исправлена.

В игре: ПКМ → **Наш отряд** → имя спутника. Для общения подойди к спутнику.
При первом запуске разреши загрузку `PersonalKnox.jar` в ZombieBuddy.

**Реакции на мир** включаются и выключаются в меню «Наш отряд». Фразы произносит сам NPC.
Реакции не отдают команд отступления и не меняют его работу. В базе SQLite сейчас 54 русские реплики.
Чтобы отряд не болтал непрерывно, пауза между фразами отряда — 20 реальных секунд,
одного NPC — 90 секунд, повтором темы — 180 секунд. Проверка выполняется раз в игровую минуту:
не более 169 соседних клеток, 256 объектов, 24 целей и четырёх спутников за проверку.
Предупреждения о зомби требуют видимости цели. Направленные предупреждения и голод пока в roadmap.

Русские подписи нашего контекстного меню находятся в языковых JSON и вызываются через `getText`,
а не записываются строками в Lua. Это также позволяет использовать английский язык как запасной.

Автосбор включается отдельно для выбранного NPC и сбрасывается при перезапуске игры.
Требование подтверждения сохраняется в данных игрока. Автосбор смотрит только текущий дом рядом
с игроком, проверяет его раз в 10 игровых минут и не запускает дальнюю самостоятельную экспедицию.
Проверка запасов пока упрощённая. Улучшение и автоматическая смена имеющегося оружия ещё не реализованы.
Грязные и заражённые тряпки не закрывают потребность в перевязочных материалах.
Минимальный резерв — две чистые повязки.
Наш мод не добавляет самостоятельного бегства; блокировка встроенного бегства Knox пока не подключена.

## Сборка и реплики

Нужен JDK 17+ и установленный ZombieBuddy. Игровые библиотеки не включены в Git.

```sh
python3 tools/build.py
```

Путь к ZombieBuddy можно передать через `--agent /path/to/ZombieBuddy.jar`.
Команда собирает Java, запускает проверки и обновляет `42/media/java/client/PersonalKnox.jar`.
Изменившийся JAR ZombieBuddy попросит разрешить повторно.

Дополнительная проверка Lua-адаптеров (в отдельном Python-окружении):

```sh
python3 -m pip install -r tools/requirements-checks.txt
python3 tools/check_lua.py
```

База реплик: `db/dialogues.sqlite3`, таблица `dialogue(id, topic, condition, text_ru)`.
Её можно редактировать любым SQLite-редактором. После изменений запусти сборку.
Сборка переносит фразы в TSV-ресурс JAR. Во время игры SQLite и сетевой сервис не нужны.
Журнал последних 100 действий/реплик хранится в `player:getModData().PersonalKnox.journal`.

## Установленная сборка

Workshop-моды перечислены в `~/Zomboid/mods/default.txt`; текущая проверка — в [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md).
Для нового мира выбери **Своя песочница → пресет Viewpoint_Squad**:
нулевой вес основных деревянных материалов, невесомые патроны/магазины,
бесконечные патроны NPC, закрывание дверей и имена NPC.
Нулевой вес дерева может повлиять на его горение; при необходимости поставь множитель 0.01.
Бесконечный запас игрока с перезарядкой обеспечивает Nepenthe's Infinite Ammo With Reload.
Для нового мира доступны Raven Creek B42, Maplewood, Iris Eyot и Dinglespurt. Их клетки не пересекаются.
В уже созданное сохранение новые карты автоматически не добавлялись.
Viewpoint Eyes добавляет настройки HUD. Полосы зомби и цифры урона отключены.
Его настройки открываются в игре: Настройки → Моды → Viewpoint Eyes → кнопка настроек.
Сохранения существующих миров установщик не изменял.

Установленные моды и наш прототип нельзя считать проверенными на отсутствие вылетов:
проверки Java не заменяют сцену с NPC, выстрелами и сбором предметов в игре.
Подтверждён запуск до главного меню со всеми 16 модами, загрузкой Java-ядра и экспортом PersonalKnoxAPI в Lua.
Подробности и следующие этапы — в [ROADMAP.md](ROADMAP.md).

## Русский интерфейс

Язык игры — RU. Перевод Knox включён отдельным модом `KnoxEventExpandedNpcRU`.
У Better Sorting, Has Been Read, Customizable Wood Weight и Map Symbol Size Slider русский встроен.
Для Viewpoint 0.1.6.1 и QOL установлен Workshop-перевод `aparosa_ViewpointI18n` (3822634333).
Наше дополнение добавляет недостающие переводы настроек веса патронов и ZombieBuddy
через `common/media/lua/shared/Translate/RU/`. Эти файлы меняют только отображаемый текст.
Для применения переводов нужен перезапуск игры; в существующем мире перевод Viewpoint
должен быть включён также в списке модов этого сохранения.

## Границы изменений

Наши Java-классы не наследуют и не изменяют классы Knox. Lua вызывает существующие команды его API.
Код и ресурсы Knox в этот репозиторий не копируются.
Условия автора Knox о Java-изменениях и публикации зафиксированы в ROADMAP.md.
